# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be direct about the work and decent to the people. Disagree with a
proposal by showing the case it breaks, not by characterising the person who
made it. Harassment, personal attacks and discriminatory language are not
tolerated anywhere the project happens — issues, pull requests, discussions.

Report a problem by opening an issue, or privately by email to the maintainer
listed in `package.json`. Reports are handled in confidence.
